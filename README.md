# AQUAROS-PLUS

## Project Overview
AQUAROS-PLUS is a Python-based academic project. This repository contains the Python source code, project presentation, editable project report, and demonstration video.

## Project Objectives
- To develop and demonstrate the AQUAROS-PLUS project.
- To provide the Python source code for reference and execution.
- To document the project through a presentation and an editable report.
- To demonstrate the project's execution through a video.

## Project Files

| File | Description |
|---|---|
| `aquaros_project.py` | Python source code |
| `AQUAROS-PLUS (1).pptx` | Project presentation |
| `AQUAROS_PLUS_Project_Report_Editable.docx` | Editable project report |
| `os project demo video.mp4` | Project demonstration video |

## Technologies Used
- Python 3

## How to Run
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program using:

   ```bash
   python aquaros_project.py
   ```
